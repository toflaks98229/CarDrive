반투명 화소가 **0 %** 입니다. 안티에일리어싱이 없다는 뜻이고, 이것이 이 게임의 결입니다.
새로 뽑는 그림도 여기를 어겨서는 안 됩니다.

## 왜 안 보이는가 — 원인 둘, 둘 다 잰 값입니다

### 1. 채도는 화면까지 못 갑니다. 살아남는 것은 휘도뿐입니다

화면 후처리(`PostPalette.mat`)가 하는 일은 셋입니다.

| 값 | 하는 일 |
|---|---|
| `_Desaturate: 0.3` | 채도를 30 % 깎아 회색 쪽으로 당깁니다 |
| `_Levels: 6` | 밝기를 **여섯 단계**로 계단화합니다 |
| `_DitherPixel: 2` | 2 화소 크기로 디더링합니다 |

여기에 스프라이트 머티리얼의 HDR 틴트가 곱해집니다. 셋의 **휘도**를 재면 이렇습니다.

| 귀신 | 머티리얼 틴트 | 틴트 휘도 | 텍스처 휘도 | 합 |
|---|---|---|---|---|
| Monter_1 (붉은) | (2.87, 0.09, 0.09) | 0.69 | 0.30 | **0.20** |
| Monter_3 (보라) | (1.43, 0.11, 2.87) | 0.59 | 0.33 | **0.19** |
| Monter_2 (흰) | (2.12, 2.12, 2.12) | 2.12 | 0.97 | **2.06** |

**흰 것이 나머지 둘의 열 배입니다.** 순색 빨강은 아무리 밝게 올려도 휘도의 21 % 밖에
쓰지 못하고(`0.2126·R`), 거기서 채도까지 30 % 깎이면 **여섯 단계 중 한가운데**로 내려앉습니다.
밤 장면이 차지하고 있는 바로 그 자리입니다.

> **규칙: 색은 정체성이고, 밝기가 시인성입니다.** 순색을 쓰면 둘 다 잃습니다.

### 2. 획이 디더 격자보다 얇습니다

가로 획 길이의 중앙값이 512 캔버스에서 **6~11 화소**이고, 얇은 쪽은 2~5 화소입니다.

5.12 m 짜리 스프라이트가 60 m 앞에 있으면 화면에서 세로 **약 88 화소**입니다.
그러면 512 기준 6 화소 획은 화면에서 **1.0 화소**가 되고, 디더 격자(2 화소)보다 얇아
**격자에 먹힙니다.** 밤 귀신 스포너가 30~60 m 고리에 놓으므로 이 거리가 실전입니다.

> **규칙: 512 캔버스에서 획 굵기 최소 16 화소.** 10 아래는 어떤 경우에도 안 됩니다.
> (16 화소 → 60 m 에서 화면 2.8 화소 → 디더 한 칸보다 굵음)

## 공통 규격 — 모든 프롬프트가 지켜야 하는 것

1. **순백 단색으로만 그립니다.** 색은 유니티 머티리얼 틴트가 입힙니다. 그래야 그림 한 장으로
   색과 밝기를 따로 조절할 수 있고, 다시 그리지 않고 시인성을 고칠 수 있습니다.
2. **배경 투명. 안티에일리어싱 없음.** 뽑은 뒤 알파를 반드시 이진화합니다(아래 후처리).
3. **획 굵기 16 화소 이상** (512 기준).
4. **실루엣이 먼저입니다.** 88 화소로 줄여도 무엇인지 알아볼 수 있는 **몸짓 하나**를 정하고,
   낙서의 잔털은 그 안쪽에만 둡니다.
5. **캔버스 세로의 60~75 %** 를 채우고 가운데 둡니다.
6. **그림자·바닥·테두리·글자 없음.** 발광도 넣지 않습니다 — 빛은 프리팹의 라이트와
   `Glow2.png` 가 만듭니다.

## 뽑은 뒤 반드시 하는 후처리

생성기는 **반투명 가장자리를 무조건 남깁니다.** 그대로 넣으면 이 게임의 결이 깨집니다.

1. **알파 이진화** — 알파 128 을 문턱으로 0 또는 255 로만 남깁니다. 지금 석 장은
   반투명 화소가 0 % 입니다. 새 그림도 0 % 여야 합니다.
2. **색 단일화** — 불투명한 화소의 RGB 를 전부 (255, 255, 255) 로 덮습니다.
   색은 머티리얼이 입힙니다.
3. **획 굵기 검사** — 가로 획 길이의 10 분위가 16 미만이면 다시 뽑거나 굵힙니다.
4. **임포트 설정** — `filterMode: Point`, `alphaIsTransparency: 1`, 스프라이트 모드 Single.
   지금 석 장과 같습니다.

```python
# 1~3 을 한 번에 하고 4번을 재는 스크립트
from PIL import Image
import numpy as np

im = np.array(Image.open(src).convert("RGBA"))
a = im[..., 3] >= 128
out = np.zeros_like(im)
out[a] = (255, 255, 255, 255)
Image.fromarray(out).save(dst)

runs = []
for row in a:
    idx = np.flatnonzero(row)
    if idx.size == 0: continue
    brk = np.flatnonzero(np.diff(idx) > 1)
    s, e = np.r_[0, brk + 1], np.r_[brk, idx.size - 1]
    runs += list(e - s + 1)
print("획 굵기 10분위:", np.percentile(runs, 10), "(16 이상이어야 합니다)")
```
