# 트럭 모델 출처

**Kenney Car Kit (1.4)** 에서 트럭 둘과 바퀴 둘만 가져왔습니다.

| 파일 | 쓰임 |
|---|---|
| `truck.fbx` | 짐칸이 덮인 트럭 |
| `truckFlat.fbx` | 짐칸이 평평한 트럭 |
| `wheelTruck.fbx` | 트럭 바퀴 |
| `wheelDefault.fbx` | 일반 바퀴 |

## ⚠ 텍스처가 없습니다

Kenney 의 차량 킷은 **색판도 UV 도 없습니다.** 부품마다 단색 머티리얼이 하나씩
붙어 있을 뿐입니다(`plastic` · `paintGreen` · `window` · `carTire` · `lightFront` ·
`lightBack` · `_defaultMat`).

그래서 이 프로젝트에는 **오히려 잘 맞습니다** — 색판을 밤 팔레트로 다시 굽는 일 없이
툰 머티리얼로 바로 갈아 끼울 수 있습니다. 바꿔 끼우는 일은
`TruckImport` 에디터 도구가 합니다.
