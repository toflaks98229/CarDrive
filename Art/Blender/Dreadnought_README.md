# Dreadnought — 2족 보행 로봇 (모델링 + 리깅)

**골격:** 카스트라페룸 패턴 드레드노트 레퍼런스 — 4 m 미만, **저자세**(보딩·터널전을 위한 패턴),
짧고 뒤로 접히는 다리 위에 동체를 바짝 얹은 땅딸막한 비례, 그리고 얼굴 노릇을 하는 평평한 **석관 전면판**.

**디자인 언어:** 스트라이더와 **같습니다.** 브루탈리스트 — 강철 섀시 위에 얹힌 콘크리트 슬래브.
모놀리식 직육면체 매스, 카세트 퓨처리즘의 투박함. **외장 장식 없음** — 돌출된 부품은 전부
구조물(힌지 핀, 강철 칼라, 유압 램, 접지 풋플레이트)입니다.

| 파일 | 위치 |
|---|---|
| 소스 (절차적 빌드 스크립트) | `Art/Blender/build_dreadnought.py` |
| 마스터 씬 | `Art/Blender/Dreadnought.blend` |
| 반입된 FBX | `Assets/_Project/04.Art/02.Models/Robot/SM_Dreadnought.fbx` |

스크립트는 멱등(idempotent)합니다. 형상을 고치려면 `build_dreadnought.py` 의 상수·치수를
고치고 다시 돌리면 같은 이름·계층으로 재생성됩니다.

```bash
blender -b --python Art/Blender/build_dreadnought.py
```

## 형태 언어 (수정 시 지켜야 할 규칙)

* 모든 구조 부재는 **직사각 단면 박스 빔**(`bbeam` / `prof_rect`). 챔퍼는 0.03~0.05 —
  하이라이트만 잡을 정도이며 실루엣을 둥글게 만들지 않습니다.
* **Bevel 모디파이어 없음.** 단면 챔퍼가 이미 그 일을 하므로 모디파이어는 폴리곤만 늘립니다.
  `finalize()` 가 익스포트 직전에 제거하고 assert 로 막습니다.
* **덩어리는 콘크리트, 어두운 강철은 좁은 띠·핀·발에만.** 이 배분이 뒤집히면
  기조가 무너집니다 — 처음 빌드가 그랬고, 큰 매스를 전부 강철로 잡아 스트라이더와 나란히
  놓았을 때 딴 기계로 보였습니다. 어두운 요소의 단면은 **그 뼈 길이의 10% 안쪽**으로 두십시오.
* 장식 금지. 유일한 비구조 요소는 센서 슬릿과 그 옆 소형 표시등 하나입니다.
  2026-09-08 에 한 번 더 걷어냈습니다 — 석관 볼트 4, 주먹 너클 4, 접지 클리트 8,
  반응로 플랜지 띠, 연장포 조준 레일. **하중이 지나가지 않으면 지웁니다.**
  남긴 것은 전부 관절이거나(고관절·무릎·발목·어깨 핀) 힘을 받는 띠(칼라·석관 테·허리 띠)입니다.

## 본 계층 (17본 / deform 12)

```
Root                        (deform X — 월드 앵커)
├─ B_Body                   동체 (고관절 축 위)
│  ├─ B_Head                센서 캡
│  ├─ B_Arm_L ─ B_Muzzle_L  (deform X — 총구 마커)
│  ├─ B_Arm_R ─ B_Muzzle_R  (deform X)
│  ├─ B_Hip_L ─ B_Femur_L ─ B_Tibia_L ─ B_Foot_L
│  └─ B_Hip_R ─ B_Femur_R ─ B_Tibia_R ─ B_Foot_R
└─ B_IK_L / B_IK_R          (deform X — 발 IK 타겟)
```

**무릎은 뒤로 접힙니다**(digitigrade). Unity 쪽 `WalkerLeg.kneePole` 도 뒤쪽을 향해야 합니다.

## 파츠 분리 구조 (파괴 연출 대응)

동체·다리는 **15개의 독립 오브젝트**로 분리되어 있고, 스키닝이 아니라 **본 페어런팅**
(`parent_type='BONE'`)으로 물려 있습니다. 스트라이더와 같은 이유입니다 — 웨이트가 본당
리지드 1.0 이라 스키닝이 하는 일이 없고, 이렇게 하면 파츠를 진짜로 떼어낼 수 있습니다.

## 팔 (교체 가능)

무기는 본체와 **별개 오브젝트**이고 원점이 어깨 피벗에 맞춰져 있어, `B_Arm_*` 밑에서
프리팹을 갈아 끼우면 그대로 정렬됩니다.

**2026-09-10 부터 무기가 다섯이고 이름이 자리로 바뀌었습니다.** 같은 무기를 양쪽에
달 수 있게 되어 종류 이름으로는 못 짓습니다. 어느 무기를 다는지는 `PATTERNS` 의
`arms=(왼쪽, 오른쪽)` 이 정합니다.

| 오브젝트 | 구동 본 |
|---|---|
| `SM_Dread_Arm_L` | `B_Arm_L` |
| `SM_Dread_Arm_R` | `B_Arm_R` |

| kind | 실루엣 | 총구까지 |
|---|---|---|
| `Fist` | 뭉툭한 주먹, 하부 총열 하나 | 1.35 m |
| `Cannon` | 굵은 원통에 총열 여섯 | 1.90 m |
| `Twin` | 가늘고 긴 관 둘 | 1.67 m |
| `Missile` | 3 × 3 발사관 격자 | 1.12 m |

**상부에도 무기 자리가 있습니다.** `top="Battery"` 또는 `"Missiles"` 로 얹습니다.
얹으면 본이 17 → 20 개가 되고 포탑이 하나 늘며, 그 포탑은 **선회가 ±180°** 입니다.

합계 688 tri. 총구 엠프티는 `SKT_Muzzle_L` / `SKT_Muzzle_R`.

## ⚠ FBX 익스포트 설정이 스트라이더와 다릅니다

`bake_space_transform=True` **를 반드시 켭니다.** 끄면 Z-up→Y-up 축 변환이 메시가 아니라
오브젝트 트랜스폼에 실려, FBX 에서 **메시만 꺼내 쓰는** Unity 반입 방식에서는 블렌더의
Z-up 인 채로 붙습니다. 켜면 단위까지 제대로 실려 임포터 배율은 1 입니다.
(`globalScale = 1`, `useFileScale = true`)
